# AI-Grading-Text

This repository contains two local AI grading project folders:

- `llm_assisted_grading/`: the researched LLM-assisted grading project, including the original processing pipeline, template files, generated batches, processed answer images, and result PDFs.
- `ai_grading_prototype/`: the minimal prototype built during the local walkthrough, including scaffold modules, sample raw answer-card images, and generated PDF score sheets.

Important local notes:

- The repository includes generated outputs and local environment files because the upload scope was requested as "push everything".
- Student answer sheets and score PDFs may contain personal information. Keep this repository private unless the data has been anonymized.
- Runtime secrets should stay in `.env` locally. Only `.env.example` should be committed.
